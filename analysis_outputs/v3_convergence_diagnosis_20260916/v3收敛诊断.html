v3 PPO 训练不收敛诊断（seed7 / 200K 训练 / 330 次更新）

数据取自 ppo_full/train.jsonl。结论：策略网络基本停在“7 候选均匀随机”，关系倾向来自候选掩码而非学习；根因是动作级因果奖励被批动作数 N 稀释、全局批奖励共模。

策略熵始终贴在均匀上限 ln7=1.946

熵 1.945→1.940 几乎不降；置信度 ~0.16 仅略高于均匀 1/7=0.143。策略没有变得确定。

策略更新幅度≈0：|KL| 噪声级、clip 命中率恒 0

330 次更新 clip_fraction 全为 0、|approx_kl|≈1e-4，新旧策略几乎相同，梯度更新近乎空操作。

验证跨片率在 0.17–0.43 震荡，无下降趋势

15 轮验证没有单调改善；同期 candidate_only 规则约 0.134–0.151。PPO 未稳定超过强规则。

奖励尺度倒挂：动作级信号被批动作数 N 稀释约两个数量级

最终验证 action_reward_mean≈3.8e-5/动作，而每批全局奖励≈5e-3（共模）；局部因果奖励在 continuous_rollout 中被除以 N。
